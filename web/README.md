# web/ — інтерфейс тренера (React + React Spectrum)

Єдиний інтерфейс до Python-бекенду: живе на `/`, адреса `/app` лишена
робочою для старих закладок. Класичний `webui.html` (60 КБ ванільного JS)
видалено — цей застосунок замінив його повністю.

Якщо `web/dist` не зібрано, сервер віддає на `/` сторінку з інструкцією
«зберіть інтерфейс», а не 404 і не JSON.

## Чому саме так

- **Залежностей рівно чотири**: `react`, `react-dom`,
  `@adobe/react-spectrum`, `vite` (+ `@vitejs/plugin-react`). Разом ~90
  пакетів. Немає роутера (хеш-роутинг у `src/store.jsx`), немає стейт-
  менеджера (один React-контекст), немає CSS-фреймворку (токени Spectrum
  + `src/index.css`), немає бібліотеки графіків (графік — рукописний SVG
  у `src/components/WpChart.jsx`).
- **У рантаймі Node не потрібен.** `npm run build` кладе статику в
  `web/dist`, `app.py` віддає її сам. Без збірки `/app` просто відповідає
  404, а решта додатка працює як раніше.

## Робота

```bash
cd web
npm install
npm run dev      # http://localhost:5173, /api і /locales проксіюються на :8765
npm run build    # -> web/dist, далі python3 app.py і http://127.0.0.1:8765/app
```

Для `npm run dev` спершу запустіть `python3 app.py` — дані беруться з нього.

## Ілюстрації

Портрети героїв і плитки карт — з `art.hearthstonejson.com`, але
**завантажуються один раз, окремим скриптом**, а не в момент перегляду:

```bash
python3 scripts/fetch_art.py --heroes   # 11 портретів, ~600 КБ
python3 scripts/fetch_art.py            # + плитки всіх колекційних карт (~36 МБ)
```

Кеш лежить у `art_cache/` (у `.gitignore` — арт належить Blizzard, ми
його не поширюємо). `app.py` віддає файли з диска через
`GET /api/art/{hero|tile|art}/{id}` і **ніколи** не ходить у мережу: якби
арт тягнувся ліниво, CDN дізнавався б, яку карту ви зараз розглядаєте —
рівно той витік, якого уникає решта коду.

Без кешу нічого не ламається: `HeroPortrait` малює герб класу
(`ClassCrest.jsx`, наші власні SVG), а `CardTile` — рамку з назвою.
Ілюстрація це бонус, а не залежність.

Кеш **не** потрапляє у зібраний PyInstaller-екзешник: 36 МБ чужого арту
всередині файлу, який роздають, — це вже поширення, а не особистий кеш.
Тому у зібраній збірці арту не буде, доки користувач сам не покладе теку
`art_cache` поруч із екзешником (`app.py` шукає її і в робочій теці, і
поруч із програмою). Інтерфейс від цього не ламається — просто скрізь
будуть герби замість портретів.

## Структура

```
src/
  api.js          усі HTTP-виклики + опитування задач (/api/job/{id})
  store.jsx       спільний стан: налаштування, колода, список ігор, хеш-роутер
  i18n.jsx        /locales/{lang}.json з сервера + strings.js для нових рядків
  strings.js      рядки, яких немає в locales/ (uk + en)
  format.js       спільне форматування рядка гри
  classes.js      кольори, герби й арт одинадцяти класів
  meta.js         назва мета-колоди -> клас (для гербів на смужках)
  components/     ui.jsx, WpChart.jsx, Board.jsx, CardTile.jsx,
                  HeroPortrait.jsx, ClassCrest.jsx, LabelLegend.jsx, …
  routes/         CoachHome, Games, GamePage, DeckLab, Settings
```

## Дизайн

Темна тема **закріплена**, а не взята з системи: кожен екран тут
тримається на артах Hearthstone, намальованих на темному тлі, і той самий
макет у світлій темі Spectrum виглядає як помилка.

Кольори класів — це кольори класів World of Warcraft, які гравець уже
читає без підпису: рядок мага бірюзовий скрізь, тож свої ігри магом ви
знаходите ще до того, як прочитали слово.

Акцент Spectrum перефарбований у латунь через його ж CSS-змінні
(`--spectrum-accent-*` в кінці `index.css`). Селектор ловить хешовані
класи по підрядку — якщо майбутній Spectrum їх перейменує, акцент тихо
стане синім; це косметика, а не поламаний екран.

## Що навмисно зроблено інакше, ніж у `webui.html`

- **Колода — один стан на весь застосунок.** Оцінка, покращення, муліган,
  суперник і нотатки тренера — вкладки однієї секції «Колода», а не п’ять
  місць, куди треба вставляти той самий деккод.
- **Огляд і реплей — одна сторінка й один плай.** Клік по ключовому
  моменту або по точці графіка переводить реплей саме туди.
- **Муліган і нотатки закриті ґейтом.** Сервер відповідає «спершу
  проаналізуйте колоду» — інтерфейс каже це до запиту, а не після
  помилки.
- **Застереження — повноцінний елемент, не дрібний сірий текст.** Графік
  шансу перемоги заштрихований на всю довжину, сірі мітки легенди
  показують, якого саме гейта їм бракує.
- **Плай є в адресі**: `#/games/12/replay/2353`. Посилання на ключовий
  момент переживає перезавантаження й ділиться з іншими.
- **Ґейт телеметрії питає сервер**, а не лише localStorage: колода,
  проаналізована в іншому браузері, більше не показується як
  непроаналізована.
- **Гаунтлет видно.** Кожна оцінка в застосунку — це «проти оцих 12
  колод», але подивитись на них було ніде. Вкладка «Гаунтлет» у секції
  «Колода» показує їх з кривою мани й повним деклистом, а коли є аналіз —
  ще й ваш вінрейт проти кожної, від найгіршого матчапу. Колода лежить в
  адресі: `#/deck/gauntlet/Attack%20Druid`.
- **З гаунтлета є шлях у гру.** Копіювання коду, копіювання списку в
  тому ж форматі, що й сайти колод, і «Взяти собі». Деккод кодується з
  сирого файлу гаунтлета — `load_meta()` для цього не годиться, бо
  сплющує сайдборд у колоду.
- **«Мета» — це тір-лист симулятора, і так і названо.** Спершу гаунтлет
  лежав під назвою «Мета», і це була неправда: мета — рейтинговий список
  із власними вінрейтами колод, а гаунтлет — бенчмарк. Тепер «Мета» —
  окрема секція, де гаунтлет грає сам проти себе (`hs2/tiers.py`), а під
  таблицею стоять три застереження й похибка вибірки.

## Текст огляду — двомовний

Огляд пишеться в базу один раз і читається роками, тож він **не може**
бути заморожений мовою, вибраною в день запуску. `eval/i18n.py` віддає
кожне повідомлення як `{key, params, text}`: ключ і числа для перекладу
плюс англійський рендер як запасний варіант для оглядів, збережених
раніше. Англійська **виводиться** з `locales/en.json`, а не набирається
вдруге, — інакше запасний варіант почав би брехати.

Рендерить це `src/msg.js`. Параметри теж перекладаються рекурсивно:
«Хід {turn}: {detail}» тримає в собі цілу іншу фразу, і переклад лише
рамки — це рівно та вада, через яку звіт спершу вийшов наполовину
українським.

`tests/test_review_i18n.py` тримає два інваріанти: кожен ключ, який
уміє видати оцінювач, існує в **обох** локалях, і англійська в payload
— це саме те, у що рендериться ключ.

## Обмеження

Назви карт і лінії леталу з солвера лишаються англійськими: у нас немає
локалізованих назв карт, а лінія — це перелік карт, а не проза.
